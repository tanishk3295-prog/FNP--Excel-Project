# FNP Sales Analysis Dashboard

## Project Overview

An interactive Excel dashboard developed to analyze FNP sales performance, customer spending, product categories, occasions, cities, and delivery performance.

## Dashboard Preview

![FNP Sales Dashboard](images/FNP_Sales_Dashboard.png)

## Key Metrics

- Total Orders: 1,000
- Total Revenue: ₹35,20,984
- Average Customer Spend: ₹3,520.98
- Average Order-Delivery Time: 5.53 days

## Analysis Covered

- Revenue by Occasion
- Revenue by Category
- Revenue by Month
- Revenue by Order Hour
- Top 5 Products by Revenue
- Top 10 Cities by Orders
- Customer Spending
- Delivery Performance

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Data Cleaning
- Data Visualization
